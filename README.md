## 🇬🇧 English

### About the Project
Vantage Coworking Space is a modern Full-Stack management system built to handle workspace reservations and event ticket bookings seamlessly. It features a robust Admin Dashboard for complete control over office spaces, events, and user accounts. Additionally, the platform integrates an intelligent **AI Agent** acting as a virtual receptionist, utilizing **Context Injection / RAG-like capabilities** to answer customer inquiries accurately based on company guidelines.

### Tech Stack
- **Backend:** C#, .NET 9 Web API, SQL Server, Stored Procedures
- **AI Orchestration:** Microsoft Semantic Kernel, OpenAI (`gpt-4o-mini`)
- **Frontend:** Angular, TypeScript, SCSS
- **Architecture:** Clean Architecture, Dependency Injection, Plugin Pattern

### Key Features
- **AI Chat Assistant:** Interactive conversational agent that answers user inquiries about pricing, locations, and rules dynamically.
- **AI Plugins & Tools:** Custom C# plugins allowing the AI to auto-invoke functions for event and workspace bookings.
- **Workspace & Event Management:** End-to-end booking lifecycle for desks, offices, and events.
- **Admin Dashboard:** Comprehensive control panel to manage spaces, organize events, and handle user accounts (suspension/activation).
