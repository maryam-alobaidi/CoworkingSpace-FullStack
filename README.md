Coworking Space System

Space & Ticket Booking System 🚀


English
This project is a comprehensive web platform designed to streamline Workspace Bookings and Event Ticket Management. It provides a dedicated Admin Dashboard to manage office spaces, organize events, and control user accounts (adding users or suspending accounts).

Backend: C# / .NET, SQL Server, Stored Procedures.

Frontend: Angular.

العربية
هذا المشروع عبارة عن منصة ويب متكاملة مصممة لتسهيل حجز المساحات المكتبية و إدارة حجز تذاكر الفعاليات. يوفر النظام لوحة تحكم متطورة للأدمن لإدارة المساحات المكتبية، إضافة الفعاليات، والتحكم في حسابات المستخدمين (إضافة مستخدمين أو تعليق حساباتهم).

الخلفية (Backend): C# / .NET, SQL Server, Stored Procedures.

الواجهة (Frontend): Angular.

Español
Este proyecto es una plataforma web integral diseñada para gestionar reservas de espacios de trabajo y gestión de entradas para eventos. Incluye un Panel de Administración dedicado para gestionar espacios de oficina, organizar eventos y controlar cuentas de usuario (agregar usuarios o suspender cuentas).

Backend: C# / .NET, SQL Server, Stored Procedures.

Frontend: Angular.
